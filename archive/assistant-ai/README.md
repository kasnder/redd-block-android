Previous In-App AI Assistant
============================

This directory archives the former networked ReDD Block assistant implementation.

The archived implementation used an in-app chat UI, a user-provided Nebius API key,
Nebius/OpenAI-compatible tool calls, and strict schedule proposal validation. It was
removed from the active Android source set when the app moved to a local
copy/paste flow where users export a prompt to their preferred AI system and paste
the AI reply back into ReDD Block for validation and review.

Files here are intentionally not compiled by the Android app.
